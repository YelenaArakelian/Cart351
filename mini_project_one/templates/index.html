    About This Project

    Constellations of Strangers is an interactive project that collects and visualizes anonymous thoughts and emotions.

    Each submission becomes a star in a collective sky. Stars are colored and connected based on their selected emotions, creating a visual representation of shared experiences.

    The project explores how personal information can be collected, categorized, and represented through data.
