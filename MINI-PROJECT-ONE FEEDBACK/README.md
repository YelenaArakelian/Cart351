## Project 1: [Face de book]

[Kerven]

### Description

_Face de Book_ is an interactive application showing its users how easily information typed inside a browser can quickly be used against you.

### What Worked Well

I liked how quickly well it worked, the website gathered the data effectively well, and peformed as how the surface intended to. I liked also how it raises awarness to how you should be careful of where you put your infornation on the web. As a victim of scams, I found this expermient crucial.

### What Could Be Improved

I understand that this type of experience happens quickly, but I wish there was a bit more interaction involved. For example, the user could be given different choices or warning signs to look out for before the scam is revealed. I think this would make the experience more engaging while also helping users better understand how easily they can fall for online scams. But overall, I still find it good.

### Suggestions

One suggestion would be to make the scam reveal more interactive. For example, when the website tells users they have been hacked, it could show different scenarios of what could happen to their stolen information, such as someone accessing their accounts or using their personal details. I think this would make the experience more impactful and help users understand the consequences of online scams.

## Project 2: [Are we sharing too much?]

[Skyla_and_Abhi]

### Description

_Are we sharing too much?_ is an interactive website where users select an item and receive an AI-generated personality assessment based on their collected data. The project aims to raise awareness about online privacy and how personal information can be used to make assumptions about people.

### What Worked Well

I really liked the concept of using a vending machine to represent how our personal data is collected and used. The 3D animations made the website visually interesting, and I thought the AI-generated personality assessments were a creative and humorous way to show how algorithms can make assumptions about us.

### What Could Be Improved

I think the overall aesthetic of the website could be improved a little, as some parts of the page feel a bit too empty compared to how creative the project itself is. Adding more visual elements or details to the background could make the website feel more complete and match the effort put into the interactive vending machine.

### Suggestions

One suggestion would be to add more decorations or details around the vending machine to make the website feel more lively. For example, adding a themed background or subtle animations could help fill the empty spaces and make the experience more immersive. I think this would also help create a stronger visual connection between the website's design and the project's concept. But overall, amazing concept!

## Project 3: [MySpace]

[Nerly]

### Description

_MySpace_ is an interactive website inspired by the original MySpace, where users can create a personal profile by entering information about themselves, their interests, and preferences.

### What Worked Well

I really liked the nostalgic aesthetic of the website, especially the pink theme and the character on the homepage. The design feels unique and playful, and I think the variety of questions makes creating a profile more personal and fun. The intention of it worked well.

### What Could Be Improved

As much as the layout of the website is aesthetically pleasing for its Y2K look, I think the layout of the form could be improved a little, as some of the text can be difficult to read against the detailed background. This makes certain sections feel a bit crowded and harder to navigate.

### Suggestions

One suggestion would be to add more customization options for users, such as choosing different themes, backgrounds, or decorations for their profiles, similar to the original MySpace. I think this would make the experience more interactive and allow users to express their personalities in a more creative way.
